# Throw in the Towel Fantasy

A season-long fantasy football companion for the league you actually play in. Connect your real ESPN or Sleeper team and it answers the week's questions: who to start, who to add, whether a trade is fair, and what your title odds really are. Every number comes with the reasoning behind it, because a projection you can't interrogate is just a guess with better posture.

**Live:** https://chukse.github.io/ttt-fantasy/

---

## The idea

Most fantasy tools hand you a preseason cheat sheet and let it rot by Week 4. We built the opposite. The projections start from a preseason prior and then get pulled toward what players are actually doing on the field, week by week, so the model you open in November is not the one you drafted with in August. The same engine feeds every screen, so your waiver read, your trade value, and your lineup all speak the same language.

We don't hide the math. Each number shows its why, and when the sample is thin or the model is unsure, we say so instead of dressing it up.

## What it does

- **Week**: your optimal legal lineup for the week, tuned to your league's scoring, plus the market movers (who's up, who's down, and by how much).
- **Waiver**: the best available players by projection and real ESPN roster percentage, with injuries and opportunity shifts already priced in.
- **Trade**: a fair-or-not analyzer built on rest-of-season value, weighted toward live form, so a hot Week 8 doesn't get valued like a career.
- **Odds**: playoff and title odds simulated over your league's actual remaining schedule, starting from everyone's real record, plus this week's matchup win probability.
- **Chat**: ask about a start/sit, a waiver add, or a trade and get an answer grounded in the app's own numbers, not a vibe.
- **Draft**: an ML draft board, a plan, and a mock you can run.
- **Team**: connect ESPN, Sleeper, Yahoo, or a manual roster, and switch between multiple leagues.

## How it stays current

The projection engine is a hybrid: a preseason prior shrunk toward live production, plus a weekly ML model re-run on real usage. On top of that it folds in live ESPN percent-rostered, a Sleeper injury feed with next-man-up opportunity redistribution, EPA-based matchup reads, and opponent-adjusted offensive line and defense rankings.

It refreshes on its own. A GitHub Action re-runs the projections twice a week (Wednesday and Sunday), and the full board rebuilds daily. The app re-checks the current week whenever you open it and rolls itself forward when a new game week starts, so you are not reading last week's matchups by accident.

## Built on open data

Everything public here runs on open data: nflverse play-by-play, the Sleeper and ESPN APIs, and our own models on top. That is a deliberate choice. The numbers are ours, and nobody can pull the feed out from under the product.

## How it's built

A single static progressive web app (HTML, CSS, JavaScript) served from GitHub Pages, installable on a phone and usable offline once loaded. A Cloudflare Worker proxies the ESPN and Sleeper calls and carries the chat and checkout. Supabase handles accounts and cloud sync so your leagues follow you across devices. The data itself is generated by a set of Python pipelines against nflverse and committed as JSON the app reads at load.

```
index.html          the whole app (UI, model math, league sync, chat)
sw.js               service worker (offline shell, auto-update)
data/*.json         projections, matchups, trenches, ADP, meta (rebuilt on a schedule)
pipeline/*.py       the refresh engines (projections, matchups, trenches)
engine/             the Cloudflare Worker (proxy + chat + checkout)
assets/             logo and static assets
```

## Running it locally

It is static, so any file server works:

```
python -m http.server 8000
# then open http://localhost:8000/index.html
```

To rebuild the data, run the pipelines (they pull nflverse and write to `data/`):

```
python pipeline/refresh_all.py --public-only          # dry run
python pipeline/refresh_all.py --public-only --deploy  # build and push
```
